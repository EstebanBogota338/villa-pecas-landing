# Villa Pecas 🏡

Landing page para Villa Pecas, un alojamiento turístico.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Responsive Design

## Características

- Página de inicio
- Información de los sitios de interés
- Galería de imágenes
- Información de contacto
- Diseño responsive
- Botónes de contacto por WhatsApp

## Objetivo

Crear una landing page moderna y sencilla para presentar Villa Pecas,
sus habitaciones y espacios, facilitando el contacto con potenciales huéspedes.
